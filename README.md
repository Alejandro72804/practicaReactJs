# 📝 practicaReactJs

Aplicación ToDo List desarrollada en React.js como práctica guiada (Platzi), enfocada en la gestión dinámica de tareas y el entendimiento del flujo de datos en el frontend.

## 🚀 Funcionalidades

* Crear tareas
* Marcar tareas como completadas / pendientes
* Conteo dinámico de tareas
* Renderizado reactivo de la interfaz
* Manejo de estado en componentes

## 🧠 Objetivo

Comprender los fundamentos de React:

* Componentes
* Props
* Estado (useState)
* Renderizado dinámico
* Interacción usuario–interfaz

## ⚙️ Instalación

```bash
git clone https://github.com/Alejandro72804/practicaReactJs.git
cd practicaReactJs
npm install
npm start
```

La aplicación estará disponible en:
http://localhost:3000

## 🛠️ Tecnologías

* React.js
* JavaScript (ES6+)
* HTML5 / CSS3

## 📌 Notas

Este proyecto forma parte de un proceso de aprendizaje práctico, enfocado en reforzar conceptos clave de desarrollo frontend con React.
